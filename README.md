# web-system-development

Repositorio de la asignatura **Web System Development** (Universidad Loyola Andalucía).

## Estructura

```
web-system-development/
├── README.md
├── exercises/
│   ├── 01/
│   │   └── index.html
│   └── 02/
│       └── index.html
└── project/
```

- `exercises/` — una carpeta por cada ejercicio del curso.
- `project/` — los archivos del proyecto principal.

## Ejecutar el ejercicio 01

```bash
cd exercises/01
npm install
npm run dev
```

Después abre http://localhost:5173
