# web-system-development

Repositorio de la asignatura **Web System Development** .

## Estructura

```
web-system-development/
├── README.md
├── exercises/
│   ├── 01/
│   │   ├── index.html
│   │   ├── Javier.html
│   │   └── Alfonso.html
│   └── 02/
│       ├── index.html
│       ├── Javier.html
│       ├── Alfonso.html
│       ├── public/
│       │   └── images/
│       └── src/
│           └── style.css
└── project/
```

- `exercises/` — una carpeta por cada ejercicio del curso.
- `project/` — los archivos del proyecto principal.

## Ejecutar el ejercicio 01

```
cd exercises/01
npm install
npm run dev
```

Después abre http://localhost:5173

## Ejecutar el ejercicio 02

```
cd exercises/02
npm install
npm run dev
```

Después abre http://localhost:5173
